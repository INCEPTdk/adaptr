# cat() with sep = ""

Used internally. Passes everything on to
[`cat()`](https://rdrr.io/r/base/cat.html) but enforces `sep = ""`.
Relates to [`cat()`](https://rdrr.io/r/base/cat.html) as
[`paste0()`](https://rdrr.io/r/base/paste.html) relates to
[`paste()`](https://rdrr.io/r/base/paste.html).

## Usage

``` r
cat0(...)
```

## Arguments

- ...:

  strings to be concatenated and printed.
