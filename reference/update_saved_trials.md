# Update previously saved simulation results

This function updates a previously saved `"trial_results"` object
created and saved by
[`run_trials()`](https://inceptdk.github.io/adaptr/reference/run_trials.md)
using a previous version of `adaptr`, allowing the results from these
previous simulations to be post-processed (including performance metric
calculation, printing and plotting) without errors by this version of
the package. The function should be run only once per saved simulation
object and will issue a warning if the object is already up to date. And
overview of the changes made according to the `adaptr` package version
used to generate the original object is provided in **Details**.  
**NOTE:** some values cannot be updated and will be set to `NA` (the
posterior estimates from the 'final' analysis conducted after the last
adaptive analysis and including outcome data for all participants), and
thus using both `raw_ests = TRUE` and `final_ests = TRUE` in the
[`extract_results()`](https://inceptdk.github.io/adaptr/reference/extract_results.md)
and
[`summary()`](https://inceptdk.github.io/adaptr/reference/summary.md)
functions will lead to missing values for some of the values calculated
for updated simulation objects.  
**NOTE:** other objects created by the `adaptr` package, i.e., trial
specifications generated by
[`setup_trial()`](https://inceptdk.github.io/adaptr/reference/setup_trial.md)
/
[`setup_trial_binom()`](https://inceptdk.github.io/adaptr/reference/setup_trial_binom.md)
/
[`setup_trial_norm()`](https://inceptdk.github.io/adaptr/reference/setup_trial_norm.md)
and single simulation results from
[`run_trials()`](https://inceptdk.github.io/adaptr/reference/run_trials.md)
when not included in as part of the returned output from
[`run_trials()`](https://inceptdk.github.io/adaptr/reference/run_trials.md)
should be re-created by re-running the relevant code using the updated
version of `adaptr`; if manually re-loaded from previous sessions, they
may cause errors and problems with the updated version of the package.

## Usage

``` r
update_saved_trials(path, version = NULL, compress = TRUE)
```

## Arguments

- path:

  single character; the path to the saved `"trial_results"`-object
  containing the simulations saved by
  [`run_trials()`](https://inceptdk.github.io/adaptr/reference/run_trials.md).

- version:

  passed to [`saveRDS()`](https://rdrr.io/r/base/readRDS.html) when
  saving the updated object, defaults to `NULL` (as in
  [`saveRDS()`](https://rdrr.io/r/base/readRDS.html)), which means that
  the current default version is used.

- compress:

  passed to [`saveRDS()`](https://rdrr.io/r/base/readRDS.html) when
  saving the updated object, defaults to `TRUE` (as in
  [`saveRDS()`](https://rdrr.io/r/base/readRDS.html)), see
  [`saveRDS()`](https://rdrr.io/r/base/readRDS.html) for other options.

## Value

Invisibly returns the updated `"trial_results"`-object.

## Details

The following changes are made according to the version of `adaptr` used
to generate the original `"trial_results"` object:

- `v1.4.0+`: updates version number and the `rescale_adapt_probs`
  argument in the embedded trial specification.

- `v1.2.0 to 1.3.2`: updates version number and the `rescale_probs` and
  `rescale_adapt_probs` arguments in the embedded trial specification.

- `v1.1.1 or earlier`: updates version number and everything related to
  follow-up and data collection lag (in these versions, the
  `randomised_at_looks` argument in the
  [`setup_trial()`](https://inceptdk.github.io/adaptr/reference/setup_trial.md)
  functions did not exist, but for practical purposes was identical to
  the number of participants with available data at each look) and the
  `rescale_probs` and `rescale_adapt_probs` arguments in the embedded
  trial specification.
